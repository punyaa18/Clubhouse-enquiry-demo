⛳ Clubhouse Enquiry Demo

A small Flask + SQLite take-home project

What this is

A simple enquiry form and staff follow-up tool for a golf club, built to be easy to run and easy to explain line by line. Visitors submit a membership, society day, or event enquiry; staff see a dashboard flagging anything that's gone 2+ days without a reply.

Python 3.11+ Flask SQLite Jinja templates Plain CSS pytest

Why this isn't running live here

This page is hosted on GitHub Pages, which only serves static files — it can't run a Flask server or an SQLite database. The actual app lives in the repo and runs locally (or on any real Python host) in a few commands.

See the README for setup, seeding demo data, and running tests.

Features

  • Public enquiry form with server-side validation and friendly error messages
  • Automatic confirmation "email" — logged to console and stored in the database
  • Staff dashboard with newest-first enquiries and a "Follow-up due" badge
  • Simulated clock (advance/reset days) so the 2-day follow-up rule is demoable instantly
  • Honeypot field + in-memory rate limiting against spam
  • Seed command for six made-up demo enquiries at different ages
